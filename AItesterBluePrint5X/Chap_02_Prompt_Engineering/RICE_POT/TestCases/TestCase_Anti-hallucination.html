Confirms that a user who opens app.vwo.com reaches the secure login page, that every login control is present, that the cursor starts in the Email address field, and that the password stays masked until the user reveals it.

Preconditions

  • 1. A new Chrome Incognito window is open (no VWO session or cookies).
  • 2. The tester has internet access to app.vwo.com.

Test data

  • URL: http://app.vwo.com/
  • Password (typed only, never submitted): Sample#Pass123
#Test stepExpected result
1Type http://app.vwo.com/ in the address bar and press Enter.The browser is redirected to https://app.vwo.com/#/login.
2Check the browser tab title.The tab title is "Login - Wingify".
3Without clicking anything, check which field has the blinking cursor.The cursor is in the "Email address" field.
4Check the controls displayed on the login form.The form shows the "Email address" field, the "Password" field, "Forgot Password?", the "Remember me" checkbox, "Sign in", "Sign in with Google", "Sign in using SSO", "Sign in with Passkey" and the "Start a free trial" link.
5Check the "Remember me" checkbox and check the page for any error message."Remember me" is unchecked and no error message is displayed.
6Click in the "Password" field and type the test password. Do not submit.The typed characters are masked.
7Click the eye icon (Toggle password visibility) next to the Password field.The password is shown as readable text.
8Click the eye icon again.The password is masked again.
